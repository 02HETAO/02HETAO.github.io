碎片知识点

  1. SCP是安全复制协议（Secure Copy Protocol）的缩写：

    • 命令格式：scp 本地源路径 用户名@远程主机IP:远程目标路径

      ​ （scp E:\Linux\猛嵌项目\4.17.rar elf1@192.168.42.128:/home/elf1/Linux_Stu/项目）

  2. 解压：

    • rar:解压到当前目录（unrar x filename.rar）；解压到指定目录（unrar x filename.rar /path/to/destination/）

    • zip:当前（unzip filename.zip）；指定（unzip filename.zip -d /path/to/destination/）

  3. **回调函数：**回调函数就是作为一个参数传递给另一个函数的函数16。外部函数会在某个特定操作（如异步任务完成、特定事件发生）完成后，再反过来“回调”并执行这个传递进去的函数

  4. gcc 工作流程：

  • gcc和g++:
    • 不管是 gcc 还是 g++ 都可以编译 C 程序，编译程序的规则和参数都相同
    • g++可以直接编译C++程序， gcc 编译 C++程序需要添加额外参数 如：gcc test.c -lpthread -o app
    • 不管是 gcc 还是 g++ 都可以定义 __cplusplus宏
