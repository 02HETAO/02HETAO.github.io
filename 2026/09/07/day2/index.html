今天是 Day 2：GCC 编译链接 + 静态库/动态库 + CMake + 结合两个真实项目理解构建过程。

今天和 Day 1 最大的区别是：

Day 1 解决“这个项目有什么”；
Day 2 要解决“这些 .cpp/.h/.so 到底是怎么变成一个能运行的程序的”。

这一天对 Linux 应用开发非常重要。以后你遇到 undefined reference、cannot find -lxxx、头文件找不到、ARM/x86 库不匹配、运行时 .so 找不到，基本都建立在今天这些知识上。

建议今天学习 5～6 小时。

一、今天最终必须达到的目标

今天结束后，你应该能够独立回答：

  1. .cpp → .i → .s → .o → 可执行文件 每一步发生了什么。
  2. 编译和链接到底有什么区别。
  3. .h / .cpp / .o / .a / .so 分别是什么。
  4. #include 和链接动态库不是一回事。
  5. include_directories() 和 target_link_libraries() 分别解决什么。
  6. 为什么 Project1 要链接 pthread / FFmpeg / MPP / RGA / RKNN / OpenCV。
  7. 为什么 Project1 中很多 .so 是 aarch64，Ubuntu x86 上不能直接运行。
  8. 能自己从零写一个小型 CMakeLists.txt。
  9. 能自己生成一个静态库和一个动态库并链接使用。

今天不要深入 MPP/RKNN 代码。
