Transforms简介

  • 用于对图像进行预处理和数据增强操作，如调整图像大小、中心裁剪、随机裁剪、随机水平翻转、归一化、将 PIL 图像转换为 Tensor 等等

  • 结构及用法：

    • from torchvision import transforms
from PIL import Image

img_path="data/train/ants_image/0013035.jpg"
img = Image.open(img_path)

#使用transforms的ToTensor()进行图片类型的转化
tensor_trans=transforms.ToTensor()
tensor_img=tensor_trans(img)

print(tensor_img)

call方法

  • 在 Python 中，call 是一个特殊方法（也称为魔术方法或双下划线方法），用于使对象可以像函数一样被调用。当你在一个对象上调用 obj() 时，Python 解释器会查找该对象的 call 方法并调用它。（相当于直接使用实例对象，不用写对应方法就直接调用call方法）

ToTensor

  • 将图像转换为Tensor，Tensor中包含很多神经网络需要的属性，便于神经网络学习，以后会经常使用到
