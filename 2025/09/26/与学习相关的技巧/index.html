与学习相关的技巧

章节简介

  • 寻找最优权重参数的最优化方法、权重参数的初始值、超参数的设定方法
  • 介绍权值衰减、Dropout等正则化方法应对过拟合
  • 介绍众多研究中使用的Batch Normalization方法
  • 使用本章介绍的方法，可以高效地进行神经网络（深度学习）的学习，提高识别精度

参数的更新

  • 最优化：神经网络的学习的目的是找到使损失函数的值尽可能小的参数。这是寻找最优参数的问题，解决这个问题的过程
  • 随机梯度下降法SGD：为了找到最优参数，我们将参数的梯度（导数）作为了线索。使用参数的梯度，沿梯度方向更新参数，并重复这个步骤多次，从而逐渐靠近最优参数的过程
  • SGD的策略：探险家虽然看不到周围的情况，但是能够知道当前所在位置的坡度（通过脚底感受地面的倾斜状况）。于是，朝着当前所在位置的坡度最大的方向前进，最终到达谷底

SGD

  • 代码实现：

    • class SGD:
    """随机梯度下降优化器 (Stochastic Gradient Descent)
    
    通过负梯度方向更新参数，是最基础的优化算法
    
    Attributes:
        lr (float): 学习率，控制参数更新的步长
    """
    
    def __init__(self, lr=0.01):
        """初始化SGD优化器
        
        Args:
            lr (float, optional): 学习率，默认为0.01
        """
        self.lr = lr  # 设置学习率
    
    def update(self, params, grads):
        """更新参数值
        
        根据梯度下降公式：param = param - lr * gradient
        对参数字典中的所有参数进行更新
        
        Args:
            params (dict): 参数字典，包含需要更新的参数
            grads (dict): 梯度字典，包含对应参数的梯度值
        """
        for key in params.keys():
            # 对每个参数执行梯度下降更新
            # 新参数值 = 原参数值 - 学习率 × 梯度
            params[key] -= self.lr * grads[key]

AdaGrad

  • 在神经网络中，学习率过小会花费很多的时间；反之过大会导致学习发散而不能正确进行

  • 学习率衰减：随着学习的进行，使学习率逐渐减小

  • AdaGrad的数学公式：以前的所有梯度值的平方和（式中的圆圈加点表示对应矩阵元素的乘法）

  • AdaGrad会记录过去所有梯度的平方和。因此，学习越深入，更新的幅度就越小。实际上，如果无止境地学习，更新量就会变为 0，完全不再更新。为了改善这个问题，可以使用RMSProp方法。

  • RMSProp方法并不是将过去所有的梯度一视同仁地相加，而是逐渐地遗忘过去的梯度，在做加法运算时将新梯度的信息更多地反映出来。这种操作从专业上讲，称为“指数移动平均”，呈指数函数式地减小过去的梯度的尺度。

  • 代码实现：

    • class AdaGrad:
    # 初始化方法，设置学习率
    def __init__(self, lr=0.01):
        # 学习率，控制参数更新的基本步长
        self.lr = lr
        # 历史梯度平方和，用于自适应调整每个参数的学习率
        self.h = None
    
    # 参数更新方法
    def update(self, params, grads):
        # 如果是第一次调用，初始化历史梯度平方和
        if self.h is None:
            # 创建空字典来存储各参数的历史梯度平方和
            self.h = {}
            # 遍历参数字典，为每个参数创建相同形状的零数组
            for key, val in params.items():
                self.h[key] = np.zeros_like(val)
        
        # 遍历所有参数进行更新
        for key in params.keys():
            # 累积历史梯度的平方和（逐元素平方）
            # 这用于记录每个参数各个方向上的梯度变化情况
            self.h[key] += grads[key] * grads[key]
            
            # 参数更新：使用自适应学习率
            # 学习率 = 基础学习率 / sqrt(历史梯度平方和 + 小常数)
            # 小常数1e-7用于防止除以零的情况
            params[key] -= self.lr * grads[key] / (np.sqrt(self.h[key]) + 1e-7)

Adam

  • Adam的特征:是融合了Momentum和AdaGrad的方法。通过组合前面两个方法的优点，有望实现参数空间的高效搜索。此外，进行超参数的“偏置校正”
  • Adam会设置 3个超参数。一个是学习率（论文中以α出现），另外两个是一次momentum系数β1和二次momentum系数β2。根据论文，标准的设定值是β1为 0.9，β2 为 0.999

权重的初始值

  • 权值衰减：抑制过拟合、提高泛化能力的技巧。简单地说，权值衰减就是一种以减小权重参数的值为目的进行学习的方法。通过减小权重参数的值来抑制过拟合的发生
