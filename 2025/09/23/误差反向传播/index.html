误差反向传播

章节简介

  • 数值微分：计算神经网络的权重参数的梯度。优点：简单易实现；缺点：计算费时间
  • 误差反向传播法：高效计算权重参数的梯度的方法
  • 理解误差反向传播法的两种方法：
    • 基于数学式：机器学习相关书籍多以数学式为中心展开论述。该方法严密且简洁，但会忽略一些根本的东西止步于式子的罗列
    • 基于计算图：可以直观地理解误差反向传播法

计算图

  • 特征：计算过程使用数据结构图形表示出来，通过多个节点和边表示

1.用计算图求解

计算步骤

  • 1.构建计算图
  • 2.在计算图上，从左到右进行计算
  • 案例：太郎在超市买了2个苹果、3个橘子。其中，苹果每个100日元，橘子每个150日元。消费税是10%，请计算支付金额

两种传播

  • 正向传播：上面的第二步“从左到右进行计算”，即是从计算图出发点到结束点的传播
  • 反向传播：从右到左，即从计算图结束点到出发点，反向传播在接下来的导数计算中发挥重要作用

局部计算

  • 计算图特征：可以通过传递“局部计算”获得最终结果
  • 局部：与自己相关的某个小范围
  • 局部计算：无论全局发生了什么，都能只根据与自己相关的信息输出接下来的结果

为何用计算图解题

  • 优点：
    • 无论全局多复杂，都可以通过局部计算使各个节点致力于简单的计算，从而简化问题
    • 利用计算图可以将中间的计算结果全部保存起来
    • 最大原因：可以通过反向传播高效计算导数
  • 示例：
    • 图中可知：支付金额关于苹果的价格的导数的值为2.2，意味着苹果每涨价1元，最终支付金额增加2.2元
  • 综上：计算图的优点是可以通过正向传播和反向传播高效地计算各个变量的导数值

2.链式法则

  • 反向传播将局部导数向反方向传递，传递这个局部导数的原理，是基于链式法则的

计算图的反向传播

  • 计算图的反向传播：沿着与正方向相反的反向，乘上局部函数
  • 计算顺序：
    • 将信号E乘以节点的局部导数
    • 将计算结果传递给下一个节点

什么是链式法则

  • 复合函数：由多个函数构成的函数
  • 链式法则是关于复合函数的导数的性质：
    • 如果某个函数由符合函数表示，则该复合函数的导数可以用构成复合函数的各个函数的导数的乘积表示

加法节点的反向传播

乘法节点的反向传播

  • 式子：z=xy

4.简单层的实现

  • 乘法节点：乘法层（MulLayer）
  • 加法节点：加法层（AddLayer）

乘法层的实现

  • 
class MulLayer:
    def __init__(self):
        self.x=None
        self.y=None

    def forward(self,x,y):  #正向传播
        self.x=x
        self.y=y
        out=x*y
        return out

    def backward(self,dout):  #反向传播
        dx=dout*self.y   #翻转x和y
        dy=dout*self.x
        return dx,dy

5.激活函数的实现

  • 实现激活函数ReLU层
  • 实现激活函数Sigmoid层

ReLU层

  • 由上式可知：如果正向传播时的输入x大于0，则反向传播会将上游的值原封不动地传给下游。反过来，如果正向传播时的x小于等于0，则反向传播中传给下游的信号将停在此处

    • ​

  • 代码实现：

    • # ReLU 层的计算图实现
class ReLU:
    def __init__(self):
        # 初始化 mask 为 None
        # mask 用于在反向传播时记录哪些位置的值小于等于 0
        # 在 forward 中会被设置为布尔数组，标记输入 x 中哪些元素 <= 0
        self.mask = None
        
    def forward(self, x):
        # 前向传播计算
        # 创建布尔掩码，标记所有小于等于 0 的位置为 True
        # 例如：x = [-1, 2, -3, 4] -> mask = [True, False, True, False]
        self.mask = (x <= 0)
        
        # 创建输入 x 的副本，避免修改原始数据
        out = x.copy()
        
        # 将掩码为 True 的位置（即 x <= 0 的位置）的值设为 0
        # 实现 ReLU 函数：y = max(0, x)
        out[self.mask] = 0
        return out
    
    def backward(self, dout):
        # 反向传播计算
        # dout: 上一层传回的梯度 ∂L/∂y
        # 返回值 dx: 本层要传回的梯度 ∂L/∂x
        # 将前向传播中 <=0 的位置对应的梯度设为 0
        # 这是因为当 x <= 0 时，∂y/∂x = 0，所以 ∂L/∂x = ∂L/∂y * 0 = 0
        dout[self.mask] = 0
        
        # 对于 x > 0 的位置，∂y/∂x = 1，所以 ∂L/∂x = ∂L/∂y * 1 = dout
        # 这里直接返回 dout（因为已经将 <=0 位置的梯度置零）
        dx = dout * 1  # 乘以 1 是为了保持维度一致，实际就是 dout 本身
        return dx

6.Affine/Softmax层的实现

Affine层

  • 仿射变换：几何学领域中神经网络的正向传播中进行的矩阵的乘积运算

  • 这里将进行仿射变换的处理实现为Affine层

  • 批处理的Affine层

  • 代码实现(dout = ∂L/∂out，其中 L 是损失函数，out 是当前层的输出)

    • class Affine:
    """仿射变换层（全连接层）"""
    
    def __init__(self, W, b):
        # 初始化权重参数
        self.W = W  # 权重矩阵 (输入维度, 输出维度)
        self.b = b  # 偏置向量 (输出维度,)
        
        # 缓存前向传播的输入，用于反向传播
        self.x = None   # 输入数据
        self.dW = None  # 权重的梯度
        self.db = None  # 偏置的梯度
    
    def forward(self, x):
        """前向传播计算：y = xW + b"""
        # 保存输入数据，用于反向传播
        self.x = x
        # 计算仿射变换：矩阵乘法 + 偏置
        out = np.dot(x, self.W) + self.b
        return out
    
    def backward(self, dout):
        """反向传播计算梯度"""
        # 计算输入x的梯度：dL/dx = dL/dout * W^T
        dx = np.dot(dout, self.W.T)
        
        # 计算权重W的梯度：dL/dW = x^T * dL/dout
        self.dW = np.dot(self.x.T, dout)
        
        # 计算偏置b的梯度：dL/db = sum(dL/dout, axis=0)
        # 沿batch维度求和，保持特征维度不变
        self.db = np.sum(dout, axis=0)
        
        # 返回输入x的梯度，用于继续反向传播
        return dx

7.误差反向传播的实现

  • 数值微分实现简单，但是计算要耗费较多的时间。误差反向传播可以高效地计算梯度

神经网络学习的全过程

  • 前提：神经网络中有合适的权重和偏置，调整权重和偏置以便拟合训练数据的过程称为学习
  • 步骤1（mini-batch）：从训练数据中随机选择一部分数据
  • 步骤2（计算梯度）：计算损失函数关于各个权重参数的梯度
  • 步骤3（更新参数）：将权重参数沿梯度方向进行微小的更新
  • 步骤4（重复）：重复步骤1、步骤2、步骤3

对应误差反向传播法的神经网络的实现

  • 代码实现（网络结构：输入层 → 仿射变换 → ReLU → 仿射变换 → Softmax损失）

    • import sys, os
sys.path.append(os.pardir)  # 添加父目录到路径，以便导入自定义模块
import numpy as np
from common.layers import *  # 导入自定义的层实现
from common.gradient import numerical_gradient  # 导入数值梯度计算函数
from collections import OrderedDict  # 使用有序字典保持层顺序

class TwoLayerNet:
    def __init__(self, input_size, hidden_size, output_size, weight_init_std=0.01):
        """
        初始化两层神经网络
        
        Args:
            input_size: 输入层神经元数量
            hidden_size: 隐藏层神经元数量  
            output_size: 输出层神经元数量
            weight_init_std: 权重初始化标准差
        """
        # 初始化权重参数
        self.params = {}
        # 第一层权重：输入层到隐藏层
        self.params['W1'] = weight_init_std * np.random.randn(input_size, hidden_size)
        self.params['b1'] = np.zeros(hidden_size)  # 第一层偏置，初始化为0
        
        # 第二层权重：隐藏层到输出层
        self.params['W2'] = weight_init_std * np.random.randn(hidden_size, output_size)
        self.params['b2'] = np.zeros(output_size)  # 第二层偏置，初始化为0
        
        # 按顺序构建网络层（有序字典保持前向传播顺序）
        self.layers = OrderedDict()
        # 第一层仿射变换：W1*x + b1
        self.layers['Affine1'] = Affine(self.params['W1'], self.params['b1'])
        # ReLU激活函数层
        self.layers['Relu1'] = Relu()
        # 第二层仿射变换：W2*x + b2
        self.layers['Affine2'] = Affine(self.params['W2'], self.params['b2'])
        
        # 最后一层：softmax + 交叉熵损失
        self.lastLayer = SoftmaxWithLoss()
    
    def predict(self, x):
        """
        前向传播进行预测
        
        Args:
            x: 输入数据
            
        Returns:
            y: 网络输出（未经过softmax的得分）
        """
        # 依次通过所有层进行前向传播
        for layer in self.layers.values():
            x = layer.forward(x)
        return x
    
    def loss(self, x, t):
        """
        计算损失函数值
        
        Args:
            x: 输入数据
            t: 监督数据（真实标签）
            
        Returns:
            loss: 交叉熵损失值
        """
        y = self.predict(x)  # 前向传播得到预测结果
        return self.lastLayer.forward(y, t)  # 计算损失
    
    def accuracy(self, x, t):
        """
        计算预测准确率
        
        Args:
            x: 输入数据
            t: 监督数据（真实标签）
            
        Returns:
            accuracy: 准确率（0-1之间）
        """
        y = self.predict(x)  # 前向传播
        y = np.argmax(y, axis=1)  # 取概率最大的类别作为预测结果
        
        # 如果监督数据是one-hot编码，转换为类别索引
        if t.ndim != 1: 
            t = np.argmax(t, axis=1)
            
        # 计算准确率：预测正确的样本数 / 总样本数
        accuracy = np.sum(y == t) / float(x.shape[0])
        return accuracy
    
    def numerical_gradient(self, x, t):
        """
        使用数值微分计算梯度（用于梯度检查）
        
        Args:
            x: 输入数据
            t: 监督数据
            
        Returns:
            grads: 包含各参数梯度的字典
        """
        # 定义损失函数（关于权重的函数）
        loss_W = lambda W: self.loss(x, t)
        
        # 计算各参数的数值梯度
        grads = {}
        grads['W1'] = numerical_gradient(loss_W, self.params['W1'])
        grads['b1'] = numerical_gradient(loss_W, self.params['b1'])
        grads['W2'] = numerical_gradient(loss_W, self.params['W2'])
        grads['b2'] = numerical_gradient(loss_W, self.params['b2'])
        
        return grads
    
    def gradient(self, x, t):
        """
        使用误差反向传播法计算梯度（高效方法）
        
        Args:
            x: 输入数据
            t: 监督数据
            
        Returns:
            grads: 包含各参数梯度的字典
        """
        # 前向传播（计算损失，同时保存各层中间结果）
        self.loss(x, t)
        
        # 反向传播
        dout = 1  # 初始梯度（从损失函数开始）
        dout = self.lastLayer.backward(dout)  # 最后一层反向传播
        
        # 反转层顺序，进行反向传播
        layers = list(self.layers.values())
        layers.reverse()  # 反转层顺序：从输出层到输入层
        
        # 逐层反向传播
        for layer in layers:
            dout = layer.backward(dout)
        
        # 从各层获取梯度
        grads = {}
        grads['W1'] = self.layers['Affine1'].dW  # 第一层权重梯度
        grads['b1'] = self.layers['Affine1'].db  # 第一层偏置梯度
        grads['W2'] = self.layers['Affine2'].dW  # 第二层权重梯度
        grads['b2'] = self.layers['Affine2'].db  # 第二层偏置梯度
        
        return grads

8.小结

  • 通过使用计算图，可以直观地把握计算过程
  • 计算图的节点是由局部计算构成的。局部计算构成全局计算
  • 计算图的正向传播进行一般的计算。通过计算图的反向传播，可以计算各个节点的导数
  • 通过将神经网络的组成元素实现为层，可以高效地计算梯度（反向传播法）
  • 通过比较数值微分和误差反向传播的结果，可以确认误差反向传播法的实现是否正确（梯度确认）
